Fluxo de cadastro e pagamento:

1. Usuário acessa a página de cadastro
2. Preenche o formulário de cadastro
3. Seleciona o plano de pagamento
4. Quando clickar ele direciona para o stripe
5. stripe validado o pagamento,  ele salva nova assinatura na tabela com os dados necessários
6. validado o pagamento ele redireciona para tela de cadastro de usuário
7. Redireciona para a tela de login
